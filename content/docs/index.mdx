# InkHive

AI-powered content pipeline that transforms one idea into a complete, publish-ready content kit.

## What it does

Provide a topic or seed article. InkHive generates:

- **Long-form blog post** — structured markdown with subheadings and conclusion
- **Social media posts** — platform-specific for Twitter, LinkedIn, Facebook, Instagram, Medium
- **Email newsletter** — subject lines, HTML, and plain text versions
- **SEO metadata** — slug, meta title, description, and keywords

All drafts are editable in a real-time UI and publishable to multiple platforms with per-channel status tracking.

## How it works

1. Create a content project from a topic or article.
2. AI generates all content variants in the background with live progress updates.
3. Edit drafts directly in the dashboard — changes save in real time.
4. Publish to connected platforms with automatic retries and error reporting.
